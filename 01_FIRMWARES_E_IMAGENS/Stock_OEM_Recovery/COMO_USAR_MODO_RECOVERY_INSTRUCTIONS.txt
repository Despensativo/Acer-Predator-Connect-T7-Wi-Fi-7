⚠️ ATENCAO: PROCEDIMENTO DE RECUPERACAO POR HARDWARE (U-BOOT RECOVERY / 192.168.1.1)
--------------------------------------------------------------------------------
Se o seu roteador travou em bootloop, nao liga o sistema operacional e nao
responde mais no terminal (Telnet/SSH) ou no IP 192.168.76.1, o unico caminho de
recuperacao fisica e atraves do bootloader de emergencia do hardware (WPS 5s):

PASSO 1: CONFIGURAR CABO DE REDE E IP FIXO NO WINDOWS
  1. Conecte um cabo de rede do seu PC diretamente na porta LAN 1 do Predator T7.
  2. No Windows, configure a sua placa de rede com IP ESTATICO manual:
     - Endereco IPv4 : 192.168.1.2
     - Mascara       : 255.255.255.0
     - Gateway       : 192.168.1.1
     (Windows: Configuracoes -> Rede e Internet -> Ethernet -> Atribuicao de IP: Manual)

PASSO 2: ACIONAR O MODO RECOVERY NO ROTEADOR (HARDWARE)
  1. Desconecte a fonte de energia (cabo de forca) do roteador.
  2. Mantenha pressionado o botao WPS no topo/traseira do roteador.
  3. Conecte a fonte mantendo o botao WPS PRESSIONADO POR 5 SEGUNDOS.
  4. Solte o botao WPS.
     --> ATENCAO: Os LEDs ficarao ESTATICOS indicando que entrou no Modo Recovery!

PASSO 3: ENVIAR O ARQUIVO DE RECUPERACAO EM: http://192.168.1.1
  Abra o seu navegador web (Chrome, Edge ou Firefox) em: http://192.168.1.1
  A tela oficial de recuperacao do U-Boot sera exibida com o botao 'Browse' / 'Upload'.

  • TESTE: O roteador vai reiniciar. Aguarde 60 a 90 segundos e veja se ele liga
    normalmente no IP original 192.168.76.1.
  • RESULTADO:
    -> SE INICIAR: Perfeito, roteador recuperado sem reinstalar nada! A partir do Slot 1,
       se você quiser consertar o Slot 2, basta abrir nossa central e usar a Opcao [3]

[ENGLISH]

--------------------------------------------------------------------------------
⚠️ ATTENTION: HARDWARE RECOVERY PROCEDURE (U-BOOT WEB RECOVERY / 192.168.1.1)
--------------------------------------------------------------------------------
If your router is stuck in a bootloop, does not boot the OS, and no longer
responds on terminal (Telnet/SSH) or IP 192.168.76.1, the only physical recovery
path is via the Qualcomm/Acer hardware recovery bootloader (WPS 5s):

STEP 1: CONFIGURE ETHERNET CABLE & WINDOWS STATIC IP
  1. Connect an Ethernet cable from your PC directly to the LAN 1 port of the Predator T7.
  2. On Windows, configure your network adapter with manual STATIC IPv4:
     - IPv4 Address : 192.168.1.2
     - Subnet Mask  : 255.255.255.0
     - Gateway      : 192.168.1.1
     (Windows: Settings -> Network & Internet -> Ethernet -> IP Assignment: Manual)

STEP 2: TRIGGER HARDWARE RECOVERY MODE ON ROUTER
  1. Unplug the power adapter from the router.
  2. Press and hold down the WPS button on the router.
  3. Plug in the power adapter while KEEPING THE WPS BUTTON PRESSED FOR 5 SECONDS.
  4. Release the WPS button.
     --> NOTICE: The LEDs will remain STATIC indicating Recovery Mode is active!

STEP 3: FLASH RECOVERY FILE AT: http://192.168.1.1
  Open your web browser (Chrome, Edge, or Firefox) and navigate to: http://192.168.1.1
  The Qualcomm U-Boot Web Recovery page will be displayed with the 'Browse' / 'Upload' button.

  OPTION A (ATTEMPT 1 - SUPER FAST / 2 SECONDS - RECOMMENDED):
