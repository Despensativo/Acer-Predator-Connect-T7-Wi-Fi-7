[PORTUGUES - BRASIL]
Este procedimento restaura o roteador para o firmware original de fabrica da Acer
direto pelo bootloader de emergencia (hardware), mesmo se o sistema operacional
estiver corrompido, em bootloop ou travado.

ARQUIVO DA ROM OFICIAL NESTA PASTA:
  ==> nand-4k-ipq5332-single_101000027.img (55.3 MB - Versao Oficial v1.01.000027)

PASSO 1: CONFIGURAR CABO DE REDE E IP NO WINDOWS
  1. Conecte um cabo de rede do seu PC diretamente na porta LAN 1 do Predator T7.
  2. No Windows, configure a sua placa de rede com IP ESTATICO manual:
     - Endereco IPv4 : 192.168.1.2
     - Mascara       : 255.255.255.0
     - Gateway       : 192.168.1.1
     (Dica no Windows: Configuracoes -> Rede e Internet -> Ethernet -> Atribuicao de IP: Manual)

PASSO 2: ACIONAR O MODO RECOVERY NO ROTEADOR (HARDWARE)
  1. Desconecte a fonte de energia (cabo de forca) do roteador.
  2. Mantenha pressionado o botao WPS no roteador.
  3. Conecte a fonte de energia MANTENDO o botao WPS PRESSIONADO POR 5 SEGUNDOS.
  4. Solte o botao WPS.
     --> ATENCAO: Os LEDs ficam ESTATICOS indicando que entrou no Modo Recovery!

PASSO 3: ENVIAR O FIRMWARE ORIGINAL PELO NAVEGADOR
  1. Abra o seu navegador web (Chrome, Edge ou Firefox) e acesse:
     http://192.168.1.1
  2. A pagina de recuperacao web do U-Boot sera exibida.
  3. Clique em 'Escolher Arquivo' / 'Browse' e selecione o arquivo desta pasta:
     nand-4k-ipq5332-single_101000027.img
  4. Clique no botao 'Upload' / 'Update' para iniciar a gravacao.
  5. AGUARDE de 2 a 3 minutos sem desligar a energia.
  6. O roteador reiniciara sozinho e ligara 100% de fabrica no IP original: 192.168.76.1
  7. Lembre-se de voltar a sua placa de rede do Windows para 'Automatico' (DHCP).

[ENGLISH]
This procedure restores the router to the official Acer factory firmware directly
via the hardware emergency bootloader (U-Boot), even if the system is corrupted,
in a bootloop, or unresponsive.

OFFICIAL ROM FILE IN THIS FOLDER:
  ==> nand-4k-ipq5332-single_101000027.img (55.3 MB - Official Acer v1.01.000027)

STEP 1: CONFIGURE ETHERNET CABLE & WINDOWS STATIC IP
  1. Connect an Ethernet cable from your PC directly to the LAN 1 port of the Predator T7.
  2. On Windows, configure your network adapter with manual STATIC IPv4:
     - IPv4 Address : 192.168.1.2
     - Subnet Mask  : 255.255.255.0
     - Gateway      : 192.168.1.1
     (Windows: Settings -> Network & Internet -> Ethernet -> IP Assignment: Manual)

STEP 2: TRIGGER HARDWARE RECOVERY MODE ON ROUTER
  1. Unplug the power adapter from the router.
  2. Press and hold down the WPS button on the router.
  3. Plug in the power adapter while KEEPING THE WPS BUTTON PRESSED FOR 5 SECONDS.
  4. Release the WPS button.
     --> NOTICE: The LEDs will remain STATIC indicating Recovery Mode is active!

STEP 3: FLASH OFFICIAL FIRMWARE IN YOUR WEB BROWSER
  1. Open your web browser (Chrome, Edge, or Firefox) and navigate to:
     http://192.168.1.1
  2. The Qualcomm U-Boot Web Recovery page will be displayed.
  3. Click 'Browse' / 'Choose File' and select the file from this folder:
     nand-4k-ipq5332-single_101000027.img
  4. Click 'Upload' / 'Update' to begin flashing.
  5. WAIT 2 to 3 minutes without unplugging power.
  6. The router will automatically reboot 100% factory clean to IP: 192.168.76.1
  7. Remember to change your Windows network adapter back to 'Automatic' (DHCP).
