================================================================================
GUIA DE RECUPERACAO DE HARDWARE VIA BOTAO WPS (FAILSAFE HTTP 192.168.1.1)
ACER PREDATOR CONNECT T7 (QUALCOMM IPQ5332)
================================================================================

ESTE PROCEDIMENTO E PARA QUANDO O ROTEADOR NAO LIGA O LINUX (BRICK / LOOP DE BOOT)
NAO PRECISA DE CABO SERIAL UART NEM DE SOLDAR NADA NA PLACA!

--------------------------------------------------------------------------------
1. OS ARQUIVOS DISPONIVEIS NESTA PASTA:
--------------------------------------------------------------------------------
- "restaurar_slot1_acer.itb":
  Chaveia a NAND (mtd3/mtd4) para o SLOT 1 (OEM v24 de fabrica 100% original).
  Use se o Slot 2 foi corrompido e voce quer voltar ao firmware de fabrica seguro.

- "chavear_slot2_acer.itb":
  Chaveia a NAND (mtd3/mtd4) para o SLOT 2 (v27 Otimizado + LuCI Porta 80).
  Use se voce esta no Slot 1 e quer ativar o Slot 2 de volta via Failsafe.

--------------------------------------------------------------------------------
2. PASSO A PASSO PARA ACIONAR O MODO FAILSAFE NO ROTEADOR:
--------------------------------------------------------------------------------
Passo 1: Desligue a fonte de energia do roteador (tire da tomada).
Passo 2: Conecte um cabo de rede da porta "LAN 1" do Predator T7 ate o seu computador.
Passo 3: Mantenha o BOTAO FISICO "WPS" PRESSIONADO na carcaca do roteador.
Passo 4: Enquanto mantem o botao WPS pressionado, conecte a fonte na tomada (ou ligue
         a chave liga/desliga).
Passo 5: CONTINUE SEGURANDO O BOTAO WPS POR 5 A 10 SEGUNDOS ate os LEDs piscarem de
         forma sincronizada / padrao de recuperacao. Em seguida, solte o botao.

--------------------------------------------------------------------------------
3. CONFIGURACAO DA REDE NO WINDOWS:
--------------------------------------------------------------------------------
O bootloader do T7 sobe um mini-servidor web de emergencia no IP 192.168.1.1 (sem DHCP).
Portanto, voce precisa fixar o IP do Windows:

1. No Windows, va em Conexoes de Rede -> Propriedades do adaptador Ethernet.
2. Em Protocolo IP Versao 4 (TCP/IPv4) -> Propriedades:
   - Endereco IP:       192.168.1.66  (ou 192.168.1.10)
   - Mascara de rede:   255.255.255.0
   - Gateway padrao:    192.168.1.1
3. Clique em OK.

--------------------------------------------------------------------------------
4. ENVIANDO O ARQUIVO VIA NAVEGADOR:
--------------------------------------------------------------------------------
1. Abra o navegador (Chrome / Edge / Firefox) e acesse:
   http://192.168.1.1

2. Uma pagina web simples de recuperacao de firmware (U-Boot Recovery) sera exibida.
3. No campo de upload ("Choose File" / "Procurar arquivo"):
   - Para voltar ao Slot 1 de Fabrica: selecione "restaurar_slot1_acer.itb"
   - Para ir para o Slot 2 Otimizado: selecione "chavear_slot2_acer.itb"
4. Clique no botao de Enviar / Upload / Flash.
5. Aguarde cerca de 30 a 60 segundos enquanto o U-Boot grava a selecao na Flash NAND.
6. O roteador reiniciara sozinho!

--------------------------------------------------------------------------------
5. APOS A REINICIALIZACAO:
--------------------------------------------------------------------------------
- Volte a placa de rede do seu computador para "Obter um endereco IP automaticamente" (DHCP).
- Se subiu no Slot 1: Acesse http://192.168.76.1 (Painel Acer Stock).
- Se subiu no Slot 2: Acesse http://192.168.73.2 (LuCI Porta 80).
================================================================================
