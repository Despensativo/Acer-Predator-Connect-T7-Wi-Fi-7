ACER PREDATOR CONNECT T7 - PACOTE COMPLETO DE DESENVOLVIMENTO OPENWRT
Hardware: Qualcomm IPQ5332 (Hawkeye A53) + QCN9224 (Wi-Fi 7) + QCA8084 PHY
========================================================================

ESTRUTURA DAS PASTAS:

1 - Firmware e Imagens OpenWrt/
    * openwrt-qualcommbe-ipq53xx-acer_predator-t7-initramfs.itb (12.6 MB)
      -> Imagem FIT completa para teste em memoria RAM (Kernel 6.18 + LuCI + ath12k).
    * openwrt-qualcommbe-ipq53xx-acer_predator-t7-squashfs-sysupgrade.bin (15.7 MB)
      -> Imagem de gravacao permanente no OpenWrt (sysupgrade).
    * openwrt_live_boot.itb
      -> Imagem formatada com gatilho de script para o Web Failsafe.

2 - Backups Originais de Fabrica/
    * appsbl.bin (1.5 MB)
      -> Dump binario integral do bootloader oficial (U-Boot 2.0 versao 25.01.17).
    * appsblenv.bin (512 KB)
      -> Particao mtd13 de variaveis de ambiente originais da Acer com CRC32 valido.
    * stock_fit_head.bin & stock_kernel_head.bin
      -> Cabecalhos originais de inicializacao da Acer.

3 - Ferramentas de Recuperacao/
    * restaurar_acer.itb (33.5 KB)
      -> Script com padding de seguranca (>10 KB) para restaurar as variaveis
         de fabrica (bootcmd=bootipq) direto pela tela Web Failsafe (http://192.168.1.1).
    * Todos os scripts Python de diagnostico, engenharia reversa, calculo de CRC e TFTP.

4 - Documentacoes e Relatorios/
    * recuperacao_e_boot_ram_acer_t7.md
      -> Manual completo do Web Failsafe (regras, trava de 10 KB, como sair).
    * relatorio_ipv6_acesso_t7.md
      -> Levantamento de portas, IPs e topologia de rede.
    * guia_teste_openwrt_acer_t7.md
      -> Guia de homologacao e testes.

5 - Codigo Fonte e DTS/
    * ipq5332-acer-predator-t7.dts
      -> Device Tree Source do Acer Predator T7 para o Kernel Linux 6.18.
    * openwrt.config
      -> Configuracao completa de compilacao do OpenWrt com drivers ath12k e LuCI.
