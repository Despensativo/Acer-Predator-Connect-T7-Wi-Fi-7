--------------------------------------------------------------------------------
1. ARQUIVO OFICIAL DE DESBLOQUEIO: config_v27_ssh_unlocked.cfg
--------------------------------------------------------------------------------
Este e o arquivo padrao de desbloqueio do Predator T7 na versao v1.01.000027.
Ele mantem o sistema oficial da Acer intacto, ativando SSH, Telnet e atalhos.

• PAINEL WEB DA ACER (Interface Grafica Original):
  - Endereco de Acesso   : http://192.168.76.1
  - Usuario de Login     : admin (ou Admin)
  - Senha do Painel      : root0100
  * Cumpre a regra obrigatoria de seguranca de 8 digitos exigida pela Acer.

• PAINEL OPENWRT LuCI (Quando ativado no Slot 2 na Porta 80):
  - Endereco de Acesso   : http://192.168.76.1
  - Usuario              : root
  - Senha                : root0100

• TERMINAL SSH (Dropbear — Porta 22):
  - Usuario              : root (ou Admin)
  - Senha                : root0100
  - Comando no Windows   : 
    ssh -o HostKeyAlgorithms=+ssh-rsa root@192.168.76.1

  * Por que aparece a mensagem "Warning: Permanently added '192.168.76.1' (RSA) to the list of known hosts"?
    Esse aviso e 100% normal e seguro. E o OpenSSH do Windows informando que 
    registrou a chave publica do roteador no seu PC (no arquivo known_hosts)
    para garantir que nenhuma outra maquina tente clonar esse IP no futuro.
    Se quiser conectar direto silenciando esse aviso, use:
    ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o HostKeyAlgorithms=+ssh-rsa root@192.168.76.1

• TERMINAL TELNET (Porta 23 — Acesso Direto de Emergencia):
  - Conecta DIRETO sem pedir senha (shell ash de superusuario)
  - Comando no Windows   : 
    telnet 192.168.76.1 23

  * O Windows nao reconhece o comando 'telnet'?
    No Windows 10 e 11, o cliente Telnet vem desativado por padrao.
    Para ativar em 5 segundos, abra o PowerShell como Administrador e execute:
    Enable-WindowsOptionalFeature -Online -FeatureName TelnetClient
    (ou pelo Prompt de Comando: dism /online /Enable-Feature /FeatureName:TelnetClient)

• REDES WI-FI 7 (Tri-Band 2.4 GHz, 5 GHz, 6 GHz e MLO):
  - Nome da Rede (SSID)  : PREDATOR T7
  - Nomes das Bandas     : PREDATOR T7_2.4GHz / PREDATOR T7_5GHz / PREDATOR T7_6GHz
  - Rede MLO (Multi-Link): PREDATOR T7_MLO
  - Senha do Wi-Fi       : 123456789
  - Seguranca / Cripto   : WPA2-PSK AES e WPA3-SAE (Universal)
  * A senha '123456789' possui 9 caracteres e funciona perfeitamente em 
    TODOS os modos de criptografia (WPA2, WPA3 e MLO) nas 3 frequencias!

2. BACKUP PURO DE FABRICA (config_v27_stock_original.cfg)
--------------------------------------------------------------------------------
Utilizado para restaurar o roteador ao estado 100% original e bloqueado:

• PAINEL WEB DA ACER:
  - Endereco             : http://192.168.76.1
  - Usuario              : admin
  - Senha                : Admin0100 (ou a senha impressa na etiqueta embaixo do roteador)

• TERMINAL:
  - SSH e Telnet estao FECHADOS (Bloqueados de fabrica).

--------------------------------------------------------------------------------
3. COMANDOS RAPIDOS DISPONIVEIS NO TERMINAL DO ROTEADOR
--------------------------------------------------------------------------------
Apos o desbloqueio, voce pode alternar entre os slots direto pelo terminal:
  - boot-openwrt  ➔ Chaveia o U-Boot para o Slot 2 e reinicia
  - boot-acer     ➔ Chaveia o U-Boot para o Slot 1 (Original) e reinicia
