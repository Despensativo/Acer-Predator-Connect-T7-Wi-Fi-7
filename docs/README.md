## Antes de seguir uma referência

- Confirme a versão, o contexto e a correspondência com os arquivos atuais.
- Para escrita de firmware, confirme o mapa físico e o rollback no dispositivo; nomes lógicos e exemplos antigos podem não identificar o alvo correto.
- Um resultado “homologado” precisa ser interpretado dentro do teste registrado. Reproduza a validação necessária à intervenção atual.
- Preserve os relatos e transcrições; consulte apenas a parte relevante em cada análise.
